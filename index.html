Protocol cheat sheet

HTTPS

Browser ↔ webmail application. Usually TCP 443 for HTTP/1.1 and HTTP/2; HTTP/3 uses QUIC/UDP.

DNS

MX locates mail exchangers. A/AAAA resolves the selected server hostname to an IP address. Usually UDP/TCP 53.

SMTP

Transfers email between mail systems. Common ports: 25 for server-to-server, 587 for message submission.

TCP

Reliable, ordered byte stream, acknowledgements, retransmission, flow and congestion control.

IMAP

Mailbox access and synchronization for compatible email clients. Common secure port 993.

POP3

Retrieves messages from a mail server. Common secure port 995.
